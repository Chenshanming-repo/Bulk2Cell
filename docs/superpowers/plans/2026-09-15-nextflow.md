# bulk2cell Nextflow implementation plan

**Goal:** Deliver an independent Conda-backed Nextflow DSL2 project at /homeb/user/repos/bulk2cell.
**Architecture:** Match bulk and single-cell libraries explicitly by sample. Refine/cluster/map/collapse PacBio reads, filter with Pigeon, export the exact bulk2cell union, build Cell Ranger and decoy-aware Salmon references, and quantify cells with the existing Python engine.
**Tech stack:** Nextflow DSL2, Conda, Python, Iso-Seq/lima/pbmm2/Pigeon, Cell Ranger 9+, Salmon 1.10.

## Constraints
- Source project and biological inputs stay read-only.
- Support HiFi and FLNC bulk BAMs; require primers for HiFi. Reject subreads and unsupported assays with actionable errors.
- Cell Ranger is user-installed proprietary software, invoked internally; all open-source environments are defined with Conda YAML.
- No biological datasets or previous result directories are copied.
